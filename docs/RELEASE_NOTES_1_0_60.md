# Release Notes - 1.0.60

## Beta review panel

This release improves the ACP pending item review experience.

### Changes

- Replaced the pending items table with review cards.
- Added a clearer review summary for each pending item.
- Displays author, category, enabled status, screenshots count, created/updated dates and support topic id.
- Displays current version metadata, compatibility, download source, file status and changelog.
- Adds quick actions for viewing the public page, editing, approving and deleting the item.
- Adds missing pending pagination variables to the ACP pending panel.

No database schema changes were introduced in this release.
