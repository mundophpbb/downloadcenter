# Checklist beta

Use este checklist antes de liberar a Central de Downloads para mais usuários.

## ACP

- [ ] Abrir Painel sem erros.
- [ ] Abrir Configurações e salvar opções.
- [ ] Criar categoria.
- [ ] Editar categoria.
- [ ] Confirmar bloqueio de exclusão de categoria com itens.
- [ ] Criar item com link externo.
- [ ] Criar item com upload local.
- [ ] Adicionar nova versão a um item.
- [ ] Escolher arquivo existente na biblioteca.
- [ ] Aprovar item pendente.
- [ ] Reprovar item pendente.
- [ ] Verificar Logs.
- [ ] Verificar Arquivos.
- [ ] Verificar Diagnóstico beta.

## Frontend

- [ ] Abrir página pública da Central.
- [ ] Usar busca.
- [ ] Usar filtro de categoria.
- [ ] Usar ordenação.
- [ ] Abrir página individual do item.
- [ ] Verificar descrição com BBCode.
- [ ] Verificar changelog com BBCode.
- [ ] Baixar arquivo local.
- [ ] Baixar link externo.
- [ ] Confirmar contador de downloads.

## Usuário comum

- [ ] Enviar ferramenta pública.
- [ ] Aceitar regras obrigatórias.
- [ ] Ver item em Meus envios.
- [ ] Editar envio próprio.
- [ ] Confirmar que edição volta para aprovação.

## Arquivos

- [ ] Confirmar que arquivo local existe fisicamente.
- [ ] Confirmar que arquivo em uso não pode ser excluído na biblioteca.
- [ ] Confirmar que arquivo órfão pode ser excluído.
- [ ] Confirmar que versão com arquivo ausente não permite download público.

## Segurança básica

- [ ] Testar upload com extensão permitida.
- [ ] Testar upload com extensão não permitida.
- [ ] Testar upload acima do limite configurado.
- [ ] Testar nome com dupla extensão perigosa.
- [ ] Confirmar que a rota de download bloqueia itens não aprovados.
