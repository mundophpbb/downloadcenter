# Release Notes 1.0.62

## Screenshot inline flow

- Screenshot upload in the ACP item editor now has a dedicated **Add screenshot** action.
- Adding a screenshot redirects back to the same item edit screen and anchors directly to the screenshots area.
- Deleting a screenshot also returns to the screenshots area.
- Added inline success messages for added/deleted screenshots.
- Clarified that screenshots are saved immediately and item data changes still require the main Save button.

No database schema changes were introduced in this version.
