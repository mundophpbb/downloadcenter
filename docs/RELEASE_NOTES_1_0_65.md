# Release notes - 1.0.65

## Focus

Improves the public and author submission flow by allowing users to include an optional screenshot together with their submitted file/link.

## Changes

- Public submission form now includes an optional screenshot upload area.
- Author edit form now includes an optional screenshot upload area.
- Author edit form now displays screenshots already attached to the item.
- Screenshot uploads use the existing protected screenshot storage and controlled route.
- Screenshot validation accepts JPG, PNG, GIF and WebP up to 5 MB.

## Notes

This version does not change the database schema. It only updates templates, controller flow, language strings and the internal version marker.
