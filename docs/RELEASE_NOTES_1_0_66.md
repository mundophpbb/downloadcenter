# Release notes 1.0.66

## Author screenshot manager

- Improved the author-side screenshot manager in **My submissions > Edit**.
- Authors can now add screenshots from the edit screen without returning to the submissions list.
- Existing screenshots are listed with thumbnails, captions and order fields.
- Authors can update screenshot captions/order.
- Authors can delete their own item screenshots.
- Screenshot changes send the item back to administrator review.
