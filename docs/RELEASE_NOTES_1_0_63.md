# Release notes 1.0.63

## Item image picker

- Reworked the ACP item image field into a managed image area.
- Added current image preview.
- Added upload support for JPG, PNG, GIF and WebP item images.
- Added support for reusing uploaded item images.
- Added support for using an existing screenshot as the item image.
- Added clear/remove action for the current item image.
- Added a controlled route for serving item images.
