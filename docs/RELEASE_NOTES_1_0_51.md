# Release notes - 1.0.51

Esta versão melhora a configuração de tópicos de suporte automáticos no ACP.

## Alterações

- O campo numérico de ID do fórum foi substituído por um seletor.
- A lista mostra apenas fóruns postáveis.
- A opção "não criar tópico automaticamente" continua disponível.
- O fórum é validado antes de criar o tópico.

## Testes recomendados

1. Abrir ACP > Central de Downloads > Configurações.
2. Selecionar um fórum para suporte.
3. Criar/editar um item marcando a criação automática de tópico.
4. Confirmar se o tópico foi criado no fórum selecionado.
5. Selecionar "não criar tópico automaticamente" e confirmar que nenhum tópico é criado.
