# Release notes - 1.0.95

ACP visual consistency and accessibility pass.

## Highlights

- Adds a consistent visual treatment for ACP guide, note, release and pending-alert blocks.
- Improves responsive behavior for ACP cards, action groups, file tools and logs filters.
- Adds clearer focus outlines for keyboard navigation.
- Improves long-text wrapping in log messages, changelogs and diagnostic boxes.
- Adds reduced-motion handling for ACP UI effects.
- Marks important dashboard/pending notices with status/alert semantics where appropriate.

No database schema changes are introduced in this release.
