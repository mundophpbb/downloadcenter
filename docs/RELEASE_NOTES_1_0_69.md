# Download Center 1.0.69

## Beta hardening: terminology and publishing rules

This release focuses on text consistency and administrator-facing configuration.

### Changed

- Replaced several user-facing occurrences of “tool/ferramenta” with more neutral phpBB-style wording such as “resource/recurso” or “item”.
- Improved submission/publishing wording in public pages, ACP labels, notifications and help text.
- Added an ACP option to require or disable the public publishing rules confirmation.
- Added an ACP field for a custom rules URL, such as a sticky forum topic.
- The built-in rules page remains available when no custom rules URL is configured.

### Notes

This version does not change the upload, screenshot or download workflows. It is intended as a low-risk beta hardening release.
