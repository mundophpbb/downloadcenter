# Release notes 1.0.61

## Item page polish

This release focuses on visual refinement of the public item page.

- Refined the item header layout and proportions.
- Added a more structured action/download card.
- Improved primary and secondary button styling.
- Improved tab appearance and spacing.
- Refined description, changelog, screenshots and older versions panels.
- Improved responsive behavior for mobile screens.

No database structure changes were introduced in this release.
