# Release notes 1.0.93

## Foco

Melhoria de documentação operacional para facilitar instalação, atualização, administração e suporte da extensão.

## Adicionado

- `docs/ADMIN_GUIDE.md`: guia administrativo com fluxo recomendado, permissões, versões, arquivos e manutenção.
- `docs/UPDATE_CHECKLIST.md`: checklist de atualização e validação pós-update.
- `docs/TROUBLESHOOTING.md`: guia de solução de problemas comuns.

## Atualizado

- `README.md` revisado para refletir a versão atual e os recursos recentes.
- `docs/INSTALL.md` ampliado com rotina pós-atualização.
- `CHANGELOG.md` atualizado.

## Compatibilidade

Esta versão não altera tabelas nem comportamento funcional. A migration apenas atualiza a versão registrada da extensão.
