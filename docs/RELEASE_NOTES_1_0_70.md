# Release notes 1.0.70

Correção de estabilidade para a configuração de regras de publicação.

## Corrigido

- Corrigido erro fatal ao acessar a página pública quando a configuração de URL/tópico externo de regras estava habilitada.
- Adicionado fallback seguro para usar a página interna de regras quando nenhuma URL externa for definida no ACP.
